Revised Asset Layers

Base retained: current login village background, slightly darkened and color-graded for readability.

Background depth: distant gate silhouette or tower, warm sky shaft/fog, subtle parallax haze.

Midground architecture: left and right house/roof cutouts that frame the login area and feel like part of the same town.

Natural environment: clustered pixel trees, shrubs, moss, and path-edge greenery that break up the hard building edges.

Foreground stage: cobblestone/bridge/path strip, barrels/crates, lantern pair, and optional signpost/notice board.

Interaction light: a soft save-point glow and atmospheric vignette behind the form, not a boxy panel.

Composition Rules

Each generated asset should look like it belongs to the same miniature set: warm window light, crisp pixel/voxel detail, shallow depth, cinematic rim light, no flat sticker edges, no isolated icons. Assets must overlap naturally and create a foreground-to-background path into the form.
