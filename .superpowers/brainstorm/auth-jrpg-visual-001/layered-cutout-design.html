Auth Screen Design: Layered Town-Gate Cutouts

Selected direction: environment-first, layered cutouts. Keep the existing background; add RPG props and light around the current auth form.

Design Goal

The screen should still feel cinematic and airy, but no longer like plain form text floating over art. The player should read the auth area as a quiet village-gate interaction point: lanterns and signposts frame the path, a subtle save-point glow sits behind the form, and foreground props create RPG depth without turning the form into a heavy pixel panel.

Generated Asset List

Required: foreground lantern pair, town-gate signpost, clustered pixel trees/shrubs, small house/roof edge cutout, subtle save-point glow overlay, cobblestone/bridge foreground strip.

Optional if first pass feels thin: small training-guild pennant, mailbox/notice-board prop, drifting warm fog overlay.

Minimal UI Polish

Do not add a heavy panel. Increase action readability, add a soft interaction halo behind the form, give the active submit/toggle controls a clearer game-menu focus state, and keep all labels accessible. Mobile gets stronger contrast and less tiny action spacing.

Implementation Boundary

Only `apps/web` UI/assets are in scope. No auth behavior changes, no Supabase changes, no engine/API/persistence changes. New assets land under apps/web/public/backgrounds/hd2d/auth/ with versioned filenames.
