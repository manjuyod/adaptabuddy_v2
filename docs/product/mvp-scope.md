# MVP Scope

The MVP is a usable mobile health loop, not the full RPG ecosystem.

## MVP Now

- Auth-linked user profile.
- Body stats: weight, height, body fat percentage, goal weight/body composition where provided.
- Exercise stats: major lifts, estimated strength inputs, fatigue, and caution zones.
- Muscle group summary data for future dashboard/body diagram views.
- Backend-owned XP events.
- Food diary with meal type, timestamp, calories, optional macros, and metadata.
- Workout plan generation for a date range.
- Workout day/exercise persistence.
- Workout session start, exercise completion, finish, status, and XP award.

## Later

- Program blending by index and user statistics.
- Override/day skip workflows beyond basic status fields.
- Barcode scanner support.
- Notification logic for stats prompts.
- Rich mobile UI implementation.

## Deferred / RPG Ecosystem

RPG features may later use XP, class selection, workout consistency, food tracking, muscle progress, and character progression. They must not be required for the mobile health MVP.
